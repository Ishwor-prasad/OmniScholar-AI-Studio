## Appendix B: Mathematical Derivations of Econometric Estimators

### 1. Ordinary Least Squares (OLS) Estimator Vector
Given the linear structural equation $Y = X\beta + \varepsilon$, the parameter vector $\beta$ is derived by minimizing the residual sum of squares:
$$S(\beta) = (Y - X\beta)^T (Y - X\beta) = Y^T Y - 2\beta^T X^T Y + \beta^T X^T X\beta$$
Differentiating with respect to $\beta$ and setting to zero:
$$\frac{\partial S}{\partial \beta} = -2X^T Y + 2X^T X\beta = 0 \implies \hat{\beta}_{\text{OLS}} = (X^T X)^{-1} X^T Y$$

### 2. Huber-White HC3 Covariance Sandwich Estimator
Under general heteroskedasticity $\mathbb{E}[\varepsilon \varepsilon^T] = \Sigma = \text{diag}(\sigma_1^2, \dots, \sigma_n^2)$, the true variance of $\hat{\beta}$ is:
$$\text{Var}(\hat{\beta}) = (X^T X)^{-1} X^T \Sigma X (X^T X)^{-1}$$
The HC3 estimator approximates $\Sigma$ by replacing $\sigma_i^2$ with $e_i^2 / (1 - h_{ii})^2$:
$$\hat{V}_{\text{HC3}} = (X^T X)^{-1} \left( \sum_{i=1}^N \frac{e_i^2}{(1 - h_{ii})^2} x_i x_i^T \right) (X^T X)^{-1}$$
where $h_{ii} = x_i^T (X^T X)^{-1} x_i$ is the $i$-th diagonal element of the hat matrix.

### 3. Welch's Robust F-Ratio for Heterogeneous Variances
When group variances are unequal ($\sigma_1^2 \neq \sigma_2^2 \neq \sigma_k^2$), Fisher's standard $F$ exhibits severe Type I error inflation. Welch's robust test calculates weights $w_j = n_j / s_j^2$ and weighted grand mean $\tilde{Y} = \sum w_j \bar{Y}_j / \sum w_j$:
$$F_{\text{Welch}} = \frac{\frac{1}{k-1} \sum_{j=1}^k w_j (\bar{Y}_j - \tilde{Y})^2}{1 + \frac{2(k-2)}{k^2-1} \sum_{j=1}^k \frac{(1 - w_j / \sum w)^2}{n_j - 1}}$$

### 4. Sobel Asymptotic Test for Indirect Mediation
The indirect transmission effect is the product of paths $a$ and $b$: $\hat{\alpha} \hat{\beta}_{\text{med}}$. The asymptotic standard error is:
$$\text{SE}_{\text{Sobel}} = \sqrt{\hat{b}^2 \text{SE}_a^2 + \hat{a}^2 \text{SE}_b^2 + \text{SE}_a^2 \text{SE}_b^2}$$
The test statistic follows a standard normal distribution under the null:
$$z = \frac{\hat{a} \hat{b}}{\text{SE}_{\text{Sobel}}} \sim \mathcal{N}(0, 1)$$

$$h_{i, j} = \text{SHA-256}(h_{2i-1, j-1} \parallel h_{2i, j-1})$$
