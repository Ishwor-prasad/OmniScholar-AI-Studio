## 🚀 Overview

OmniScholar v1.0.0 is the world's first **full-lifecycle empirical research and publishing platform**. Built for university researchers, thesis scholars, and quantitative analysts, it guides users through the complete scientific publishing pipeline:
1. **Research Inception & Theoretical Framing** (Topic ➔ Literature Gap ➔ Conceptual Model ➔ Hypotheses)
2. **Survey Instrumentation & Data Ingestion** (Likert Scales ➔ Automated Google Forms via Apps Script ➔ Pilot Simulation ➔ CSV/Excel upload)
3. **Econometric & Statistical Inference** (ANOVA, Kruskal-Wallis, Mann-Whitney, OLS HC3, Cook's D, 300 DPI Charts)
4. **Bitwise Integrity Ledger** (SHA-256 Provenance & Zero-Ghostwriting Seal)
5. **Peer Review Defense Council** (Pre-emptive Q1 Reviewer Risk Matrix)
6. **Camera-Ready Publishing** (Sub-second Typst IEEE Engine, LaTeX Booktabs, and Complete ZIP Bundle)

Every calculation is strictly derived from raw empirical vectors using a deterministic Python sandbox—guaranteeing **0.0% ghostwriting hallucination** with cryptographic SHA-256 provenance.

## 🌟 Key Capabilities

### 1. Stage 1: Research Framing & Theoretical Hook
- Enter any custom research topic or pick one of 4 domain benchmarks (Stock Market Volatility, Educational AI, Social Media & Mental Health, Telemedicine).
- Automatically synthesizes an **Unresolved Literature Gap**, an **IV ➔ MOD ➔ DV Conceptual Model Architecture**, and **3 Directional Hypotheses ($H_1, H_2, H_3$)**.

### 2. Stage 2: Survey & Empirical Data Hub
- Formulates a 12-item psychometric Likert survey questionnaire mapped directly to the conceptual constructs.
- Compiles ready-to-run **Google Apps Script** code that automatically creates a live Google Form in 3 seconds.
- **Pilot Data Simulator ($N=100$)**: Synthesizes correlated empirical responses that feed immediately into the downstream analytics pipeline.
- **Multi-Format Dataset Ingestion**: Drag-and-drop support for `.csv`, `.xlsx`, and `.xls` datasets.

### 3. Stage 3: Variable Profiler & Econometrics Engine
- **Descriptive Statistics**: Sample size ($N$), missing values, mean, $SD$, median, $\text{IQR}$, min, max, skewness ($\gamma_1$), and kurtosis ($\gamma_2$).
- **300 DPI Distribution Graphics**: Publication-grade distribution charts and ranked frequency horizontal bar charts.
- **Bivariate Correlation Matrix**: Computes Spearman rank correlation matrix and high-resolution annotated heatmaps.
- **Parametric & Non-Parametric Hypotheses**: One-way ANOVA, Welch's $t$-test, Kruskal-Wallis $H$-test, and Mann-Whitney $U$-test with dynamic grouping variables.
- **Econometric OLS Regression**: Heteroskedasticity-consistent HC3 standard errors, Cook's Distance outlier diagnostics, and Tukey HSD post-hoc comparisons.

### 4. Stage 4: Bitwise Integrity Ledger
- SHA-256 cryptographic hashing of the active dataset.
- Bitwise math traces recording every input vector, transformation step, and resulting statistic.
- Anti-Ghostwriting Verification seal certifying 0.0% hallucination probability.

### 5. Stage 5: Peer Review Defense Council
- Evaluates statistical vulnerability against top-tier Q1 journal peer review standards.
- Pre-emptively analyzes sample size constraints, normality deviations, multicollinearity risks (VIF), and common method bias.
- Provides bulletproof reviewer rebuttal templates.

### 6. Stage 6: Camera-Ready Publishing Studio
- **High-Speed Typst Compiler**: Sub-second compilation of publication-quality IEEE two-column PDF manuscripts (`manuscript.typ` ➔ `Research_Manuscript_v1.0.0.pdf`).
- **LaTeX Booktabs**: Formats empirical tables into standard academic syntax (`\toprule`, `\midrule`, `\bottomrule`).
- **Cryptographic Reproducibility Passport**: Exports mathematical provenance JSON certificates.
- **One-Click Research Bundle**: Downloads a comprehensive `.zip` package containing compiled PDFs, high-res 300 DPI figures, raw CSVs, LaTeX/Typst sources, and audit logs.

- **Verification:** Independent verification test suite with SciPy/Statsmodels numerical baselines.

## ⚡ Quickstart

### Launching the Application
From the repository root:
```cmd
start_omnischolar.bat
```
Or from PowerShell:
```powershell
.\start_omnischolar.ps1
```

Or from the `version 1.0.0/app` directory:
```bash
python server.py
```

Access the studio at:
👉 **`http://127.0.0.1:8000`**
